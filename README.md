# LLM_STUDY - 贵金属周频量化策略系统

这是一个面向**黄金（XAUUSD）与白银（XAGUSD）**的周频策略原型系统，适合你“我手工下单、系统负责给建议+做复盘”的使用方式。

## 你能得到什么

- 每周策略建议（买入/卖出/观望）
- 建议的价格区间（买入区间、卖出区间）
- 每条建议对应的解释理由（来自多因子评分）
- 你手工交易后，记录交易并自动更新收益报表
- 简单账户表：现金、持仓市值、权益、累计收益率

## 策略设计（系统自动构建）

系统融合 5 类因子并打分：

1. **趋势因子**：4周均线 vs 12周均线
2. **动量因子**：4周收益动量
3. **均值回归因子**：12周 z-score
4. **金银比因子**：黄金/白银比值的20周偏离程度
5. **波动率因子**：8周收益波动，用于降低高波动期激进度

评分阈值：

- `score >= 1.5`：买入/加仓
- `score <= -1.5`：卖出/减仓
- 其他：观望/持有

同时按 ATR 近似值生成操作区间：

- 买入区间：`当前价 - 0.8*ATR` 到 `当前价 - 0.2*ATR`
- 卖出区间：`当前价 + 0.2*ATR` 到 `当前价 + 0.8*ATR`

## 文件结构

- `strategy_system.py`：主程序（信号 + 交易记录 + 报表）
- `data/weekly_prices.csv`：示例周线行情
- `data/manual_trades.csv`：你的手工交易记录（示例）
- `output/portfolio_report.csv`：运行后生成的账户报表

## 安装依赖

```bash
python -m pip install pandas numpy
```

## 运行策略（生成本周建议 + 报表）

```bash
python strategy_system.py
```

你会在终端看到：

- 黄金、白银各自的动作建议
- 买卖价格区间
- 因子理由
- 账户最新权益与累计收益率

## 记录你的手工交易

例如记录一笔“买入黄金”：

```bash
python strategy_system.py \
  --add-trade \
  --symbol XAUUSD \
  --side buy \
  --price 2650 \
  --qty 3 \
  --datetime "2026-01-09 10:30"
```

然后系统会把交易追加到 `data/manual_trades.csv`，并立即重算报表。

## 你后续可以怎么用

- 每周跑一次命令，拿到本周建议与区间
- 你执行后，把真实成交价和时间记录进系统
- 用 `output/portfolio_report.csv` 查看自己的收益演变
- 以后可继续拓展因子（宏观、利率、美元指数、持仓报告等）

> 说明：当前仓位管理采用简化模型（不含手续费、滑点、保证金规则），用于策略研究和交易辅助提醒。
